# Serial Cantonese quality release

The working branch is based on `b9e23979c6f3ad3929e876a2d86d706f12ac7ae8`,
before the throughput experiment. The experiment commit `35074d4` remains on its
own branch and must not be merged for this release. Source and English groups
remain serial and retain their original small limits and all three English
passes.

## Correctness changes

- New jobs freeze `source-guard-v2`; deployed old snapshots retain their existing rule
  versions, request bodies and successful provider responses.
- Linked English repairs are one transaction. A partially blocked year move
  cannot erase the election condition from another cue. Only a source-supported
  relocation of the same year may pass the numerical gate; financial value and
  unit changes are held for evidence.
- Annual bond-yield facts are extracted from the approved Cantonese numerals,
  including decimal continuations across the word 厘. This is not a global
  interest-unit conversion: monthly loan contexts and uncertain 幾 amounts are
  excluded. A source-consistent paragraph cannot silently lose its election
  event, approaching condition or yield scale just because all IDs are present.
- A narrow gap feel/fill rule applies to an explicit Cantonese gap-filling
  context, not ordinary English "I feel". English cannot add an unspoken gap
  direction or overnight event, or change filling to merely reaching a level.
- Source text describing funds still inside and rotating is not new inflow.
  Exact supported repairs preserve every numerical token and source timestamp.
- Consumer Staples identity can be checked against an original same-object XLP
  frame. Ordinary stable adjectives and an unrelated frame are not replacement
  authority. Original ASR and source-review changes remain in the record.
- Spoken decimal quantities, including a final Chinese digit, stay one amount.
  Percent continuations across cues are checked only when the paragraph owns
  the complete amount. Ambiguous source numerals are not truncated into a
  confidently parsed suffix. A point is not assumed to mean percent.
- A return to a neckline cannot silently become a crossing above it. A sector
  recovering because rates fall cannot become a sector that is falling, or
  repeat the same recovery as two independent claims. Source-grounded guards
  reject those candidates and preserve the recorded schema-repair limit.
- English paragraph generation is one shared three-stage helper used by the
  normal serial workflow and targeted regression. This does not introduce a
  second translation implementation or change the production batch sizes.
- 星期 is recognized as a week qualifier, avoiding a false unsupported-duration
  alarm. Same-model audit findings remain inspectable; a raw critical count is
  not a measured error count or automatic acceptance.

Lexicon: `2026-10-28.1`, 44 rules and five guidance records.
English rules: `2026-10-28.general.2`, 39 general rules.

## Original video limits removed at the user's request

The Cantonese UI, upload stream and media probe have no application size or
duration ceiling. Config returns `maxBytes: null` and `maxMinutes: null`.
Uploads stream to disk; there is no whole-video RAM buffer or fixed upload-body
timeout. File type, nonempty input, valid duration and audio presence remain
checked. Each provider audio request stays bounded, with contiguous source-time
coverage. The provider timeout and request-size constraints are separate from
original-video limits.

Long periodic frame lists no longer recurse indefinitely beyond 240 samples.
Local extraction/silence-processing timeouts scale with media duration. This
does not certify arbitrary physical storage/network capacity or measure a full
multi-hour paid job. The original tus upload-domain path is unchanged; Cantonese
uses its own direct Caddy/Node upload route.
The local legacy demo frontend and its probe also use the same unlimited media
policy, so an alternate route cannot retain a hidden 512 MB / 30-minute cap.

## Validation and evidence boundaries

The tests cover the previously observed linked-patch loss with different source
years, tenfold yield failures with different values, supported/unrelated source
quotes, percent/percentage-point protection, inflow/inside distinctions, true
gap-up controls, unresolved sector names, and serial three-stage cached resume.
Large-video tests cover a declared upload over 512 MB without allocating that
body, a 12 GB browser File description, multi-hour probe acceptance, long-frame
coverage and contiguous bounded audio chunk plans.

A copy of the completed original 230-cue job was replayed with real caches and
network calls prohibited. All source-review and English rows were identical;
successful request fingerprints were reused without another provider call.

The real quality regression deliberately reuses the original serial-run ASR and
source evidence. It makes a separate assistant source revision (gap spelling
and Consumer Staples) and generates English serially with new rule snapshots.
It is not a fresh audio-recognition benchmark, a blind evaluation or a full-film
human listening pass. References are read for diagnosis and post-generation
comparison, not supplied to the translation request. Matching an old English
draft and reference is cross-support, not proof that a spoken value is true.

## Release verification

The local full suite passes 147 tests, including real FFmpeg extraction and
loopback HTTP tests with mocked model responses. Runtime media smoke passes.
The completed 230-row pre-throughput source/English cache replay also passes
with all network calls forbidden. Original times, IDs and source-unit coverage
are preserved in the quality revision.

The real MiniMax regression first generated all 55 original small English
paragraphs with draft, review and audit. Five affected groups were regenerated
with the same production helper, and the remaining causal group was checked
again after its failure exposed a new guard requirement. Successful responses
and all rejected candidates are retained locally. No reference English was
included in those translation requests; this is an assisted regression after
diagnosis, not a new blind holdout or a full audio-recognition rerun.

Known review limits remain: an ambiguous spoken index amount, a source/reference
precision disagreement, short ASR fragments, and technical terms split across
cue boundaries. They do not justify changing values from memory or treating
the reference as infallible. The exported subtitles remain an assisted draft;
human final approval and YouTube playback are not asserted.
